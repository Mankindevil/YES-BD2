## 原攻略要点

- 包含零利润商品、顺带刷成就：购买 205 组，原攻略金额为 1,086,400。
- 排除零利润商品：购买 195 组，原攻略金额为 1,062,400。
- 红框内的商品按攻略为零利润；不刷成就时不收藏、不购买这些商品。
- 红框分布在角色游戏卡 1、2、3、7，以及活动游戏卡 1、2、3、5、7；活动卡 7 有两组。
- 截图中的黄星表示收藏，灰星表示不收藏。图中售罄字样是作者截图时的库存状态，不表示应取消收藏。

金额与利润沿用原攻略的购买数量和折扣条件，仅供对照；工具不会以这个金额直接下单，也不实时更新本攻略。

## 在 YES-BD2 中使用

1. 重启更新后的工具，游戏使用简体中文和 16:9 窗口。
2. 打开「跑商」→「按攻略设置收藏」，选择方案（默认「只买有利润商品」）。
3. 点击「开始设置收藏」。会替换 31 个商店已有的收藏：按方案加入或取消星标。只进入普通商店，不砍价、不购买。
4. 完成后按需运行原有「每日跑商」，由它购买游戏内收藏并执行你开启的后续步骤。

收藏设置不加入每日批量任务，也不覆盖出售日历。需要保留自定义收藏时，请继续手动设置，不运行此入口。

途中停止或切换方案后重新运行，会从头核对全部卡带，正确的星标不会重复切换。若有卡带未解锁、识别失败或商品数量变化，会停止并保留已改星标；状态显示未全部完成，核对截图后再重试。商品顺序改变但数量不变仍需人工核对本地攻略，新版本游戏不能仅凭数量判断兼容。
